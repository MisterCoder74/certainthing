Key Features

💬 Conversational AI Chat

Describe your application in natural language — no syntax, no structure constraints. The AI interprets your intent and generates working code, iterating through conversation until you're satisfied.

🧠 Reasoning Pane

Watch the AI plan, structure, and implement your project in real time. Every architectural decision is visible — total transparency.

📎 Multimodal Input

Upload images, text documents, or paste URLs. Want to recreate a site's layout? Paste the URL and the Website Analyzer extracts structure and style automatically.

👁️ Live Preview & 🚀 One-Click Deploy

Every generation renders instantly in a sandboxed preview. When you're ready, deploy to a permanent personal URL, export as ZIP, or push to GitHub — all with one click.

📂 Deploy Manager

Centralized panel to manage all your deployments: browse files, edit code in-browser, delete, download, copy public links. All from one authenticated interface.

🎙️ Voice Prompt

Click the mic button in the toolbar and speak — your words appear in the prompt field in real time. After 2.5 seconds of silence the recording stops automatically, or click again to stop manually. No extra API key needed: recognition runs entirely in the browser, using the language set in your OS. Available on all plans; disabled with a tooltip in unsupported browsers (e.g. Firefox).

⚙️ Model Selector (Paid Plan)

Paid users can choose the AI model directly from the chat toolbar: gpt-5-nano (default — fast and cost-efficient) or gpt-5.4-nano (more refined output for complex tasks). The selected model is shown in the Reasoning Pane on every response.

💾 Session Persistence

Every project is a session saved in JSON. Recall every session at will, resume where you left off without losing context or conversation history.

🐛 Empathetic Debugger

Paste or upload your code, you will receive a complete empathetic debug report of what's working and what's not... plus, it doesn't make you feel dumb!
