CertainThing nasce a Pomezia, nel cuore del Lazio, dall'esperienza di Vivacity Design AI Division — la divisione di intelligenza artificiale di Vivacity Design Web Agency, fondata da Alessandro Demontis.

Non è un prodotto importato e localizzato. Allo stesso tempo, CertainThing parla un linguaggio universale: l'interfaccia è in inglese per garantire compatibilità internazionale, e lo stack tecnologico vanilla lo rende deployabile su qualsiasi hosting nel mondo — dal provider italiano al server cloud globale.

Scarica l'intero progetto come archivio ZIP con un click. Tutti i file, pronti per essere caricati su qualsiasi hosting o integrati in un progetto esistente.

Integrazione diretta con GitHub: fai push del progetto su un repository con un click. Perfetto per versionamento, collaborazione e deployment automatizzato.

🔍 Website Analyzer

Puoi caricare files di codice, incollare codice o screenshot direttamente nel prompt, facendo analizzare a CertainThing siti web esistenti per estrarre struttura, layout e stile come contesto per l'AI. Ideale per ricreare o trarre ispirazione da design esistenti.

Architettura Tecnica

Stack Tecnologico

  • Backend: PHP — nessun framework, nessuna dipendenza esterna
  • Frontend: HTML5, CSS3, JavaScript vanilla
  • Persistenza: File JSON — nessun database richiesto
  • AI Engine: OpenAI API (gpt-5-nano) via BYOK
  • Autenticazione: Custom login con bcrypt hash
  • Pagamento: Stripe (€4.99/mese, 7 giorni trial)

Persistenza Dati

CertainThing utilizza file JSON per tutta la persistenza — nessun database SQL richiesto. Questo significa:

  • Zero configurazione — niente MySQL, PostgreSQL o MongoDB da installare
  • Portabilità totale — copia la cartella e hai un backup completo
  • Leggibilità — i dati sono ispezionabili direttamente con un editor di testo
  • Hosting minimale — funziona su qualsiasi hosting con PHP, anche i più economici

Domande Frequenti

Cos'è il Vibe Coding?

È un approccio allo sviluppo software dove il tuo intento creativo guida la creazione. Descrivi la tua app in linguaggio naturale e l'AI traduce la conversazione in codice funzionante, gestendo l'implementazione tecnica mentre tu ti concentri sulla visione.

Che tipo di input supporta?

CertainThing è multimodale: accetta testo naturale, immagini, documenti di testo e URL. Puoi caricare uno screenshot di un design, un file con specifiche o l'URL di un sito esistente per fornire contesto all'AI.

Devo saper programmare?

No. CertainThing è progettato per tutti — dal principiante assoluto allo sviluppatore esperto. Se sai descrivere quello che vuoi, puoi usarlo. Il Reasoning Pane ti mostra cosa sta facendo l'AI ad ogni passaggio.

Quanto costa davvero?

L'abbonamento è €4.99/mese con 7 giorni di prova gratuita. L'AI funziona con la tua API Key OpenAI (modello gpt-5-nano): paghi solo i token che consumi, circa $0.25 per 1M di token. Nessun credito, nessun blocco, nessun costo nascosto.

Perché è meglio dei competitor più famosi?

Tre motivi concreti: 1) Costa 4-10 volte meno senza limiti di token. 2) Genera codice vanilla che funziona ovunque, non codice legato a framework specifici. 3) Zero configurazione — apri il browser e lavori. Non serve installare nulla.

Su che hosting posso pubblicare le app create?

Su qualsiasi hosting che supporti PHP — anche i piani gratuiti o da €1-2/mese. Non serve Node.js, non servono container Docker, non serve serverless. Un normalissimo hosting condiviso basta.

Posso usare il codice generato per progetti commerciali?

Sì. Il codice generato è tuo. Puoi usarlo, modificarlo e distribuirlo per qualsiasi scopo, personale o commerciale.

Come funziona il sistema BYOK?

BYOK sta per "Bring Your Own Key". Nella configurazione inserisci la tua API Key di OpenAI. L'AI di CertainThing usa il modello gpt-5-nano tramite la tua chiave — i costi dei token vengono addebitati direttamente sul tuo account OpenAI, dandoti pieno controllo e trasparenza sui consumi.

CertainThing è sicuro?

Sì. L'autenticazione usa bcrypt hash, i percorsi dei file sono protetti contro path traversal, e la tua API Key è salvata nel tuo profilo utente — non viene condivisa con nessuno. Tutti i dati risiedono sul server di CertainThing, non su servizi terzi (salvo le chiamate API a OpenAI per la generazione).

È già disponibile?

Sì. CertainThing è in early access beta. Puoi registrarti gratuitamente e provarlo per 7 giorni senza impegno.

7 giorni gratuiti. Nessuna carta di credito richiesta per la prova.
