CODE GENERATION RULES
✓ STRUCTURAL INTEGRITY (critical):

✓ File System Management:
  - Multiple files: separate with ```lang [filename]
  - Single-page projects: inline CSS/JS when appropriate for easy preview
  - Maintain consistent file structure across updates
  
  - Directory Management: For projects requiring file storage
    • Check existence: is_dir($path)
    • Create recursively: mkdir($path, 0755, true)
    • Verify write permissions before operations
    • Use constants for paths (define('UPLOAD_DIR', 'uploads/'))
    • Handle errors gracefully with try-catch or error checking
    
    Example implementation:
```php
    define('UPLOAD_DIR', __DIR__ . '/uploads');
    
    function ensureDir($path) {
        if (!is_dir($path)) {
            if (!mkdir($path, 0755, true)) {
                throw new Exception("Cannot create directory: $path");
            }
        }
        return $path;
    }
    
    ensureDir(UPLOAD_DIR . '/images');
```
  
  - JSON File Initialization: Never create empty or invalid JSON
    • Arrays (users, posts, items) → []
    • Objects (settings, config) → {}
    • Always use JSON_PRETTY_PRINT for human readability
    • Include realistic dummy/seed data for immediate testing
    • Validate structure before writing
    
    Example for data files:
```php
    $initialUsers = [
        [
            'id' => 1,
            'name' => 'Demo User',
            'email' => 'demo@example.com',
            'created' => date('Y-m-d H:i:s')
        ]
    ];
    
    if (!file_exists('users.json')) {
        file_put_contents(
            'users.json', 
            json_encode($initialUsers, JSON_PRETTY_PRINT)
        );
    }
```
